# Database-Management-Systems-Project
 A simplified recreation of Tokopedia's e-commerce database using SQL and Oracle APEX

## Project Overview
This project recreates the fundamental database structure of Tokopedia as a relational database. The database is designed to represent the core transaction process between buyers and sellers.

The project includes several database components such as:
- Buyer data
- Seller data
- Product data
- Product categories
- Payment data
- Order data
- Order details
- Relationships between entities

The database structure was designed using an Entity Relationship Diagram (ERD) and implemented using SQL through Oracle APEX.

## Database Process
The recreated database represents the basic transaction flow within an e-commerce platform:

Buyers are registered in the system.
- Sellers and their shops are registered.
- Sellers add products and assign them to categories.
- Buyers place orders for products.
- Payment information is recorded.
- Order details store the products and quantities purchased.
- The database stores the relationships between the transaction data.

The project focuses specifically on the transaction process and does not cover other parts of the Tokopedia system such as logistics, advertising, or customer service.

## Database Structure

The database consists of seven main tables:
- Buyers
- Sellers
- Categories
- Products
- Payment
- Orders
- Order_Details

Each table contains attributes and relationships that represent the fundamental data required for the transaction system.

## Project Highlights
The main focus of this project is to recreate the fundamental database structure of Tokopedia and understand how different entities within an e-commerce transaction are related to each other.
The project demonstrates the implementation of database relationships as well as fundamental SQL concepts such as joins, views, set operators, aggregate functions, and subqueries.

## Project Outcome
The final result is a simplified recreation of Tokopedia's database structure that represents the fundamental transaction process between buyers, sellers, products, payments, and orders.
Through this project, I gained an understanding of how an e-commerce transaction system can be represented and implemented using a relational database and SQL.
